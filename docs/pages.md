# 页面地图

| 路径 | 页面 | 说明 |
|------|------|------|
| `/auth/login` | 登录 | 不走布局 |
| `/auth/register` | 注册 | 不走布局 |
| `/dashboard` | 总览 | 余额、Quota、汇率 |
| `/tokens` | API Key 管理 | 创建/删除 Token |
| `/logs` | 使用日志 | 按条件查询 |
| `/billing/recharge` | 充值 | 金额 + 币种 + 支付方式 |
| `/billing/records` | 账单 | 流水记录 |
| `/playground` | 调试工具 | 流式测试 |
| `/settings` | 个人设置 | 昵称/邮箱/展示币种 |
